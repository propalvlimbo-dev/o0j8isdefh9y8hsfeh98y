# Клан над головой, титул только в табе

Коротко о задаче: над головой должно быть **донат + ник**, а если игрок в клане —
**донат + клан + ник**. Титул при этом остаётся в табе и над головой не появляется.

## Почему титул сейчас висит над головой

В TAB это две **разные** настройки, и их легко перепутать:

| Что настраиваем | Ключ в TAB | Где видно |
|---|---|---|
| Строка в списке игроков (Tab) | `tabprefix`, `tabsuffix` | таб по клавише Tab |
| Строка над головой (неймтег) | `tagprefix`, `tagsuffix` | над головой в мире |

Титул у вас приходит из `%luckperms_suffix%` (в конфиге TAB он ещё и подменяется
на `&#F8BEFB БЕТА` через `placeholder-output-replacements`). Значит, где-то в
`groups.yml` или `users.yml` плагина TAB этот суффикс прописан в `tagsuffix` —
поэтому он и виден над головой.

Задача решается так: из `tagsuffix` титул убираем, в `tagprefix` добавляем клан,
а `tabsuffix` с титулом оставляем как есть.

## Шаг 1. ElytrixClans уже готов

Плагин отдаёт плейсхолдер `%elytrixclans_clan_tag%`:

- игрок **в клане** → `[Название] ` в цвете уровня клана (с пробелом на конце);
- игрок **без клана** → **пустая строка**.

Именно поэтому у безклановых над головой не останется ни скобок, ни лишнего пробела.

Вид тега меняется в `plugins/ElytrixClans/config.yml` без пересборки:

```yaml
clanTagFormat: "&7[%color%%clan%&7] "
```

`%clan%` — название, `%color%` — цвет по уровню клана из `levels.yml`.
Например, чтобы убрать скобки: `clanTagFormat: "%color%%clan% "`.

После правки — `/elytrixclan reload`.

## Шаг 2. Правки в TAB

### 2.1. `config.yml` — секция `scoreboard-teams`

Секция у вас уже включена, ничего добавлять не нужно. Главное, чтобы
`scoreboard-teams.enabled` оставался `true` — именно он рисует неймтеги.

### 2.2. `groups.yml` — основная правка

Это ваш текущий файл. Титул над головой даёт строка `tagsuffix`:

```yaml
default:
  tagsuffix: '&r%luckperms_suffix%'   # <-- титул над головой
_DEFAULT_:
  tagsuffix: '%luckperms_suffix%'     # <-- и здесь тоже
```

Замените содержимое `plugins/TAB/groups.yml` на это (готовый файл лежит
рядом — `groups_TAB_готовый.yml`):

```yaml
per-world: []
default:
  # Таб: донат + ник + титул (как было)
  tabprefix: '%luckperms_prefix%&7'
  tabsuffix: '%luckperms_suffix%'
  # Над головой: донат + клан + ник, титула нет
  tagprefix: '%luckperms_prefix%%elytrixclans_clan_tag%&7'
  tagsuffix: ''
_DEFAULT_:
  tabprefix: '%luckperms_prefix%&7'
  tabsuffix: '%luckperms_suffix%'
  tagprefix: '%luckperms_prefix%%elytrixclans_clan_tag%&7'
  tagsuffix: ''
```

Что изменилось ровно в двух местах каждой группы:

- `tagsuffix` стал пустым — титул над головой пропал;
- в `tagprefix` добавлен `%elytrixclans_clan_tag%` — появился клан.

`tabprefix` и `tabsuffix` не тронуты, так что таб выглядит как раньше.

Про `&7` в конце `tagprefix`: он красит ник в серый и должен остаться
последним, уже после тега клана — иначе цвет клана «потечёт» на ник.

Блоки `default` и `_DEFAULT_` — это разные вещи: `_DEFAULT_` применяется ко
всем группам, у которых нет своей секции, а `default` — к конкретной группе
с именем «default». Правим оба, как в примере.

### 2.3. Обновление тега при смене клана

Чтобы клан над головой менялся сразу после вступления или выхода, добавьте
в `config.yml` TAB интервал обновления:

```yaml
placeholder-refresh-intervals:
  default-refresh-interval: 500
  '%elytrixclans_clan_tag%': 1000
  # ... остальные ваши строки без изменений
```

### 2.4. Применить

```
/tab reload
```

## Результат

- Игрок без клана, над головой: `[Донат] Ник`
- Игрок в клане, над головой: `[Донат] [Клан] Ник`
- В табе у обоих: `[Донат] Ник БЕТА` — титул на месте, клана нет.

## Если титул всё равно остался над головой

1. Проверьте `users.yml` в TAB — персональная настройка игрока перебивает группу.
2. Титул может добавлять не TAB, а другой плагин (например, сам LuckPerms через
   `nametag`-модуль стороннего плагина). Тогда отключать нужно там.
3. Включите в TAB `debug: true` и посмотрите `/tab debug <ник>` — он покажет,
   какое значение и из какой группы подставляется в `tagprefix`/`tagsuffix`.

## Прочие плейсхолдеры плагина

| Плейсхолдер | Значение | Без клана |
|---|---|---|
| `%elytrixclans_clan_tag%` | `[Клан] ` в цвете уровня | пусто |
| `%elytrixclans_clan_name%` | название в цвете уровня | пусто |
| `%elytrixclans_clan_name_plain%` | название без цветов | пусто |
| `%elytrixclans_clan_name_board%` | название для скорборда | `Без клана` |
| `%elytrixclans_clan_level%` | уровень клана | пусто |
| `%elytrixclans_clan_exp%` | опыт клана | `0` |
| `%elytrixclans_clan_role%` | роль игрока в клане | пусто |

В скорборде у вас уже стоит `%elytrixclans_clan_name%` — там для строки
«Клан: …» лучше подходит `%elytrixclans_clan_name_board%`: он покажет
«Без клана» вместо пустоты.
